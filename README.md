# Multiparty Authorization for RESTful Provisioning Protocol (RPP)

This repository contains the IETF draft for using multiparty authorization to allow 3rd parties to make RESTful Provisioning Protocol (RPP) API requests.

The [draft](https://github.com/SIDN/ietf-rpp-multi-party-authorization/blob/main/src/draft-wullink-rpp-multi-party-authorization.md) is authored using [mmark](https://mmark.miek.nl/) Markdown.

Contributions in the form of a Pull Request are welcome.

For generated output see:
[Plaintext](https://sidn.github.io/ietf-rpp-multi-party-authorization/draft-wullink-rpp-multi-party-authorization.txt)  
[HTML](https://sidn.github.io/ietf-rpp-multi-party-authorization/draft-wullink-rpp-multi-party-authorization.html)  
[PDF](https://sidn.github.io/ietf-rpp-multi-party-authorization/draft-wullink-rpp-multi-party-authorization.pdf)  
[XML](https://sidn.github.io/ietf-rpp-multi-party-authorization/draft-wullink-rpp-multi-party-authorization.xml)

## Command Line Usage

Requirements:

- [mmark](https://mmark.miek.nl/)
- [xml2rfc](https://github.com/ietf-tools/xml2rfc#installation)

Formatted versions can be built using:

```sh
cd src
make all
```
